# Student-Database-Management-System
Student Database Management System – A Java-based console application that performs CRUD operations to manage student records. Features include search, sorting, statistics generation, input validation, and efficient data handling using Java Collections and Streams API.


# Student Database Management System

## 🚀 Technologies Used
- Java (Servlets, JSP)
- MySQL
- JDBC
- HTML, CSS, JavaScript
- Apache Tomcat

## 📌 Features
- Student Registration
- Login Authentication
- CRUD Operations
- Database Integration

## 🎯 Description
A full-stack web application to manage student records efficiently, reducing manual work and improving accuracy.

## ▶️ How to Run
1. Import project in Eclipse
2. Configure Tomcat Server
3. Setup MySQL database
4. Run on server
