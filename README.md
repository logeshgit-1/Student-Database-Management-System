# Student-Database-Management-System
Student Database Management System – A Java-based console application that performs CRUD operations to manage student records. Features include search, sorting, statistics generation, input validation, and efficient data handling using Java Collections and Streams API.

# 🎓 Student Database Management System

## 📌 Overview
The Student Database Management System is a Java-based console application designed to efficiently manage student records. It provides a menu-driven interface to perform CRUD operations and analyze student data.

## 🚀 Features
- ➕ Add new student records
- 📋 Display all students
- 🔍 Search students by ID, Name, or Department
- ✏️ Update student details
- ❌ Delete student records
- 📊 View statistics (Average CGPA, Highest, Lowest, Topper)
- 🔃 Sort students by Name and CGPA
- ✅ Input validation and exception handling
- 🔐 Ensures unique email for each student

## 🛠️ Tech Stack
- Java
- Java Collections Framework (ArrayList)
- Java Streams API

## 📂 Project Structure
- `Main.java` – Handles user interaction and menu system
- `StudentDatabase.java` – Core logic for CRUD operations and data handling
- `Student.java` – Model class for student entity
